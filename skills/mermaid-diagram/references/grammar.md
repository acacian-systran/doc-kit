# 그림 문법

**모양이 저장소의 종류를, 색이 역할을 말한다.** 라벨을 읽기 전에 구조가 먼저 보이게
하려는 것이다. 색 정의는 `_palette.mmd` 한 벌뿐이다. Mermaid 에는 import 가 없어서
각 그림 끝에 `%% palette:begin` ~ `%% palette:end` 블록으로 붙여 넣고,
`sync_palette.py` 로 맞춘다. 그림 파일에 색상값을 직접 적지 않는다.

`_` 로 시작하는 파일은 그림이 아니라 자재다.

## 어휘

### 모양 — 노드 문법이 정한다 (flowchart)

| 문법 | 모양 | 뜻 |
|---|---|---|
| `id["x"]` | 사각형 | 단계 · 그 밖의 것 |
| `id[("x")]` | 실린더 | DB — 행을 보관하는 곳 |
| `id@{ shape: doc, label: "x" }` | 문서 | 파일시스템 |
| `id{{"x"}}` | 육각형 | 트리거 — 무엇이 실행을 부르나. 우리 시스템 안이 아니다 |
| `id{"x"}` | 마름모 | 조건 게이트 — 여기서 대상이 줄어든다 |
| `id[["x"]]` | 서브루틴 | 다른 그림에 있는 것 — 여기서 펴지 않는다 |
| `id(["x"])` | 스타디움 | 시작 · 끝 (필요할 때만) |

`@{ shape: ... }` 는 v11.3+ 문법이다. `cyl`·`doc`·`docs`·`hex`·`diam`·`subproc`·
`lin-cyl`(디스크)·`h-cyl`(큐) 등 30여 종. 클래스는 다음 줄에 `id:::클래스` 로 따로 준다.

### 색 — 클래스가 정한다

| 클래스 | 뜻 | 보이는 것 |
|---|---|---|
| `ext` | 외부 — 우리가 만들지 않은 것 | 회색 점선 |
| `trigger` | 트리거 (육각형과 짝) | 노랑 |
| `step` | 단계 — 무언가를 하는 곳 | 파랑 |
| `filter` | 거르는 단계 · 조건 게이트 | 청록 |
| `file` | 파일시스템 (문서 모양과 짝) | 노랑 |
| `table` | RDB (실린더와 짝) | 회색 |
| `canon` | 정본 — 잃으면 복구가 어렵거나 비싼 것 | 회색 + 굵은 테두리 |
| `index` | 색인 — 검색을 받는 곳 (실린더, 색만 보라) | 보라 |
| `nondet` | 비결정 — LLM 이 닿는 것 | 주황 |
| `tbd` | 미확정 — 설계가 아직 정하지 않은 자리 | 붉은 점선 |
| `ro` | 조회 — 쓰기가 하나도 없는 것 | 초록 |
| `note` · `warn` | 각주 — 상자가 아니다 | 테두리 없는 글자 (회색 · 붉은색) |

클래스 이름이 ASCII 인 이유: block-beta 의 lexer 가 한글 식별자를 거부한다. flowchart
는 한글 클래스명을 받지만 한 벌을 쓰려면 낮은 쪽에 맞춘다.

**정본의 모양은 정본이 있는 곳을 따라간다.** 파일시스템에 있으면 문서 모양, DB 로
이관하면 실린더. 굵은 테두리의 뜻만 그대로다.

### 선 — 종류가 정한다

`linkStyle` 은 순번 기반이라 선을 하나 더하면 뒤의 번호가 다 밀린다. 쓰지 않는다.
선의 뜻은 선의 종류로 가른다.

| 문법 | 뜻 |
|---|---|
| `==>` | 축. 이것만 따라가면 전체가 읽힌다 |
| `-->` | 부수 — 받아오는 것 · 남기는 것 |
| `-.->` | 읽기만 하는 흐름 · 선택 · 비동기 |
| `--x` | 막힘 · 버림 · 종료 |
| `<-->` | 왕복 — 라벨에 오가는 것을 적는다 |
| `-->|"라벨"|` | 선 위 라벨. 짧게. 조건은 선이 아니라 마름모에 |

### 컨테이너 — `subgraph` + `style`

`subgraph id["제목"] ... end`. 색은 classDef 가 아니라 `style id ...` 로 준다
(팔레트 끝의 주석에 세 벌). **점선 = 논리 그룹, 실선 = 배포 경계.** "같이 묶여 있나"와
"같이 죽나"는 같은 말이 아니다. 배포 경계를 점선으로 그리면 "이 안은 한 번에 내려간다"를
말할 수단이 없어진다.

`subgraph` 안의 노드가 밖과 이어지면 그 subgraph 의 `direction` 은 무시된다. 안의
방향을 지켜야 하면 밖과 잇는 선을 subgraph 자체(`id`)에 건다.

## 배치

Mermaid 는 자리를 정해 주지 않는다. D2 의 격자처럼 "왼쪽 = 받는 것, 오른쪽 = 남기는 것"을
강제할 수 없다 — 그러려면 `block-beta` 인데, 간격이 없고 선이 짧아 읽히지 않는다(시험해
봤다). 대신 다음으로 다스린다.

**축을 `==>` 로 이어 두면 레이아웃 엔진이 축을 한 줄로 세운다.** 부수 선(`-->`)은 옆으로
빠진다. 이것이 격자의 대체물이다.

**선이 상자를 관통하면 대개 배치가 아니라 그림이 인과를 건너뛴 것이다.** 오가는 상대를
인접 단계로 옮긴다. 고치고 나면 대개 사실에도 더 가깝다 (분석은 적재 프로세스가 아니라
적재가 남긴 것을 읽는다).

**`TD` 가 기본이다.** 단계가 7개를 넘어 세로가 길면 `LR` 로 눕힌다. `LR` 에서 상자
라벨이 길면 폭이 터지므로 `<br/>` 로 두 줄로 끊는다.

**컨테이너형은 `layout: elk`.** 기본 dagre 는 중첩 subgraph 안에서 선이 상자를 관통한다.
GitHub 는 elk 를 지원하지 않아 dagre 로 그린다 — 거기서도 읽히는지 한 번 본다. 읽히지
않으면 SVG 를 이미지로 넣는다.

**왕복은 한 선으로 합친다.** `a --> b` 와 `b --> a` 를 따로 그리면 되돌아가는 선이 배치를
끌어당긴다. `a <-->|"요청 · 응답"| b`.

**부연은 설명하는 subgraph 안에 `note` 노드로 둔다.** 밖에 두면 엔진이 아무 데나 놓는다.
안에 두면 테두리가 대상과 묶어 준다. 붙일 subgraph 가 없는 것(사람 등)은 투명 subgraph
로 한 겹 싼다.

**범례는 상자가 스무 개를 넘을 때만.** `note` 클래스 노드 하나로 쓴다. 이어진 선이
없으니 엔진이 위쪽 빈자리에 놓는다 — 그 자리로 족하다.

## 무엇을 그리지 않나

**조건은 라벨의 괄호가 아니라 마름모다.** `filter` 색을 입고 자기 칸을 갖는다. 괄호로
묶으면 조건인지 부연인지 구분되지 않는다.

**판단의 근거는 `%%` 주석에 남긴다.** 왜 이 게이트를 두지 않았는지, 왜 이 순서인지는
그림에 그리지 않는다 — 근거 문서의 파일명과 절 번호를 주석으로 적는다.

**구현 여부는 그리지 않는다.** `tbd`(붉은 점선)가 말하는 것은 **설계가 아직 정하지 않은
자리**다 — 벤더 미정, 근거 문서에 해당 행 없음. 설계가 정한 것은 아직 만들지 않았어도
보통 상자다. 구현 진척을 그림에 표시하면 그림을 유지하는 데 대조 작업이 붙고, 대조를
전제한 그림은 갱신 의무를 지며, 갱신 의무가 붙은 그림은 반드시 낡는다. 진척은 그림
디렉터리 README 의 "그린 시점" 절에 글로 적는다 (`diagrams-readme.md`).

**관점 그림은 모듈이 가진 것을 다시 그리지 않는다.** 관점 그림(경계·런타임·시간)은
여러 모듈을 한 장에 담고, 모듈 그림은 한 모듈을 깊게 판다. 관점 그림에서 남의 모듈은
`[["x"]]`(서브루틴) 한 상자다 — 단계는 모듈 그림에 있다.

**같은 사실이 두 그림에 있으면 한쪽이 낡는다.** 남는 것이 그림 한 장을 유지할 값이
안 되면 지운다.

## 그림을 언제 나누나

한 그림은 질문 하나에 답한다. 답하는 질문이 둘이면 그림을 둘로 나눈다.

**"한 대상이 지나가는 순서"와 "한 실행이 도는 순서"가 다르면 반드시 나눈다.** 비동기
대기(제출과 회수 사이 24시간)가 끼면 한 프로세스가 대상을 끝까지 들고 있을 수 없어
둘이 갈라진다. 앞은 flowchart · state, 뒤는 sequence 다. 한 장에 그리면 축이 "대상이
이 순서로 지나간다"로 읽히는데 그것이 거짓이다.

**참여자가 여섯을 넘는 sequence 는 시스템을 그리고 있는 것이다.** 컨테이너형으로 간다.

**번호는 실행의 산물이다.** 실행 순서를 묻지 않는 그림에서는 단계 번호를 뗀다. 번호를
남기면 축을 따라 `4 → 5 → 3 → 6` 같은 것이 나오고, 사실은 맞아도 첫 독자가 오타로
읽는다. sequence 의 `autonumber` 도 같은 기준이다.

**번호를 다시 매길 때 빈자리를 남기지 않는다.**

## 유형별 문법 요점

### flowchart

```
---
title: 제목
config: { theme: base, layout: elk, flowchart: { curve: basis } }
---
flowchart TD
%% 주석은 유형 선언 뒤에. frontmatter 와 선언 사이에 두면 파서가 깨진다.
  a["라벨"]:::step
  b@{ shape: doc, label: "파일" }
  b:::file
  a ==> b
  subgraph g["그룹"]
    c["x"]:::step
  end
  style g fill:#FCFCFB,stroke:#8A94A0,stroke-dasharray:4 3
  classDef step fill:#EFF5FC,stroke:#2E5C8A,color:#1F3A5A
```

라벨 안의 줄바꿈은 따옴표 안에서 실제 줄바꿈 또는 `<br/>`. 마크다운 강조는
``["`**굵게** 보통`"]``. `htmlLabels: true` 가 기본이다.

### sequenceDiagram

`actor`(사람) · `participant`(시스템). `->>` 호출, `-->>` 응답, `--x` 실패, `-)` 비동기.
`loop` · `alt/else` · `opt` · `par` 블록. `rect rgb(r,g,b)` 로 구간에 색 — 비결정 구간은
`rgb(253, 240, 227)`(팔레트의 nondet fill). `Note over A,B: x`. classDef 는 없다.

### stateDiagram-v2

한글 상태 이름은 `state "표시명" as id` 로 두고 id 는 ASCII — `class id 클래스` 문이
한글 id 를 받지 않는다. 중첩은 `state id { ... }`. 전이 라벨은 사건(무엇이 일으키나)이고
동작이 아니다. classDef 를 받는다 — 팔레트 블록을 그대로 붙인다.

### erDiagram

`A ||--o{ B : "동사"`. 기호는 각자 쪽의 카디널리티 (`||` 1 · `o|` 0..1 · `}o` 0..N · `}|` 1..N).
속성 블록은 `타입 이름 PK|FK|UK "부연"`. 한글 엔터티·속성 이름은 그대로 된다. classDef
없음. 열을 다 적으면 스키마 덤프지 그림이 아니다 — 뜻을 정하는 열만.

### gantt

`dateFormat YYYY-MM-DD` · `axisFormat %m/%d` · `excludes weekends`. 작업은
`이름 :태그, id, 시작|after id, 기간`. 태그 `crit`(밀리면 전체가 민다) · `active` ·
`done` · `milestone`(기간 0d). 의존은 날짜가 아니라 `after` 로 — 앞이 밀리면 같이 민다.
색은 `mermaid.config.json` 의 themeVariables(`taskBkgColor` · `critBkgColor` 등)가 정한다.

### mindmap

```
mindmap
  root((주제))
    가지
      잎
```

들여쓰기가 구조다. 모양 `(( ))` 원 · `( )` 둥근 · `[ ]` 사각 · `)) ((` 구름. 스타일은
`:::클래스` 만 받고 `classDef` 는 받지 않는다 — 기본 테마로 둔다. 구조 없는 나열에만
쓴다. 선후·인과가 있으면 flowchart 다.

## 함정 — 파서 오류의 대부분

| 증상 | 원인 | 고침 |
|---|---|---|
| `Parse error on line 1 … %%%%flowchart` | frontmatter 와 유형 선언 사이에 `%%` 주석 | 주석을 선언 **뒤로** |
| `%%` 라벨의 상자가 생김 · ER 파서가 `%` 에서 멈춤 | 내용 없는 `%%` 한 줄 | `%% ·` 처럼 무엇이든 붙인다 |
| 라벨이 `4 ·` 에서 잘림 | `<LLM …>` 이 HTML 태그로 먹힘 (`htmlLabels`) | 라벨에 `<` 를 쓰지 않는다. 자리표시자는 「」 |
| title 에 `&lt;` 가 보임 | frontmatter title 은 HTML 이스케이프됨 | title 에 `<>` 금지 |
| `Lexical error … classDef 단계` | block-beta 에 한글 클래스명 | 팔레트의 ASCII 이름 |
| `Lexical error … class 검토 filter` | stateDiagram `class` 문에 한글 id | `state "검토" as review` |
| `end` 노드가 파서를 깨뜨림 | `end` 는 예약어 | `End` · `END` · 다른 이름 |
| 라벨의 괄호·콜론이 파서를 깨뜨림 | 따옴표 없음 | `["라벨 (부연): x"]` 로 감싼다 |
| subgraph 안 direction 무시 | 안의 노드가 밖과 이어짐 | 선을 subgraph id 에 건다 |
| elk 인데 GitHub 에서 다르게 보임 | GitHub 는 elk 미지원 | dagre 로도 확인하거나 SVG 이미지로 |
| 선 하나 더했더니 다른 선 색이 바뀜 | `linkStyle 3` 순번 밀림 | linkStyle 을 쓰지 않는다 |
