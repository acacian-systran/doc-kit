(`vaswani-2017-attention`). 소문자, 하이픈, 관사(a·the) 제외.

## 3. 채운 예시

앵커가 어떤 밀도로 붙는지, 결과와 주장이 어떻게 갈리는지 보이기 위한 예시다.

```markdown
# Attention Is All You Need

> 순환·합성곱 없이 주의 기제(attention)만으로 만든 인코더-디코더가 기계번역에서 기존
> 최고 성능을 넘으면서 학습 비용은 훨씬 적다.

## 서지

| | |
|---|---|
| 저자 | Vaswani 외 7인 (Google Brain · Google Research) |
| 출처 | NIPS 2017 (arXiv:1706.03762v7) |
| 링크 | https://arxiv.org/abs/1706.03762 |
| 코드 | https://github.com/tensorflow/tensor2tensor (§7, p.10) |
| 읽은 범위 | 본문 1-11쪽 |

## 연구 목적

순환 신경망 기반 시퀀스 변환 모델은 은닉 상태를 위치 순서대로 계산하므로 학습 예제
내부에서 병렬화가 되지 않고, 이 제약은 시퀀스가 길수록 심해진다 (§1, p.2). 주의 기제는
이미 여러 과제에서 쓰이고 있었지만 대개 순환 신경망과 함께 쓰였다 (§1, p.2). 저자들은
순환 구조를 완전히 걷어내고 주의 기제만으로 입출력 사이의 전역 의존을 잡는 구조를
목표로 삼는다 (§1, p.2).

## 연구 방법

인코더와 디코더를 각각 6개 층으로 쌓고, 각 층을 멀티헤드 자기주의와 위치별 순전파망으로
구성한다 (§3.1, p.3). 순환 구조가 없어 위치 정보가 사라지므로 사인·코사인 위치 부호화를
입력 임베딩에 더한다 (§3.5, p.6). 학습은 WMT 2014 English-German 450만 문장쌍과
English-French 3600만 문장쌍에서 수행했고 (§5.1, p.7), 8× P100 GPU 한 대에서 base 는
10만 스텝 12시간, big 은 30만 스텝 3.5일이 걸렸다 (§5.2, p.7). 최적화는 Adam(β₁=0.9,
β₂=0.98)에 웜업 4000 스텝의 학습률 스케줄을 썼다 (§5.3, p.7).

## 주요 결과

WMT 2014 EN-DE newstest2014 에서 Transformer (big) 이 BLEU 28.4 로, 앙상블을 포함한
기존 최고 기록을 2.0 BLEU 이상 넘어선다 (Table 2, p.8). 학습 비용은 2.3×10¹⁹ FLOPs 로,
같은 표의 앙상블 모델들(1.1~1.2×10²¹)보다 두 자릿수 작다 (Table 2, p.8). EN-FR 은
Table 2 가 41.8, 본문 §6.1 이 41.0 을 적고 있어 **원문 안에서 값이 어긋난다** (p.8) —
인용할 때는 어느 쪽을 쓰는지 밝혀야 한다. 번역 외에 영어 구구조 분석(WSJ 4만 문장)에서도
과제별 조정 없이 경쟁력 있는 결과를 냈다 (§6.3, p.9-10; Table 4, p.10).

## 결론

저자들은 이 결과를 근거로, 주의 기제만으로 된 구조가 순환·합성곱 층을 대체할 수 있으며
학습이 훨씬 빠르다고 주장한다 (§7, p.10). 다른 양식(이미지·오디오·비디오)으로의 확장과
국소 주의 기제를 후속 과제로 든다 (§7, p.10).

## 한계와 향후 연구

**저자가 밝힌 것**
큰 입출력을 다루려면 전역 주의 대신 국소·제한 주의가 필요하다고 본다 (§7, p.10).
생성이 여전히 순차적이라는 점도 과제로 남긴다 (§7, p.10).

**읽으며 든 의문**
BLEU 는 단일 값으로만 보고되고 시드에 따른 분산이 없다 (Table 2, p.8) — 0.4 수준의 차이가
유의한지 판단할 근거가 논문 안에 없다. 구구조 분석 실험은 하이퍼파라미터를 거의 조정하지
않았다고 밝히고 있어 (§6.3, p.10), 일반화 주장의 강도가 번역 결과만큼은 아니다.

## 키워드

self-attention, multi-head attention, positional encoding, sequence transduction,
machine translation

## 어디에 인용하나

순차 계산이 병렬화의 병목이라는 문제 설정, 주의 기제 단독 구조의 최초 제시,
학습 비용 대비 성능을 논거로 쓸 때. 최신 성능 수치의 근거로는 쓰지 않는다 — 2017년 값이다.
```

예시에서 눈여겨볼 것 — 결과 절에는 표에서 온 수치만 있고 "구조가 단순하다" 류의 평가가
없다. 원문의 수치 불일치를 감추지 않고 결과 절에 적었다. 한계 절이 저자와 나로 갈려 있어
독자가 누구의 판단인지 안다.
