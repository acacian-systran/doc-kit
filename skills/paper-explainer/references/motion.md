# 움직임

움직임은 **위치 · 순서 · 인과**를 보여 줄 때만 쓴다. 꾸미려고 쓰지 않는다.
모든 움직임은 `prefers-reduced-motion: reduce` 에서 꺼지고, 꺼져도 내용은 다 보인다
(`site.css` 맨 끝). 새 움직임을 추가할 때도 이 규칙을 지킨다.

## 1. 자동으로 붙는 것 (손댈 것 없음)

| 움직임 | 보여 주는 것 |
|---|---|
| 미니맵 레일 채움 | 이전 페이지에서 채워 둔 높이에서 현재 단계까지 레일이 차오른다. 앞으로 왔는지 되돌아갔는지가 보인다 |
| 현재 섹션 바닥 막대 | 이 페이지를 얼마나 읽었는지. 스크롤에 따라 찬다 |
| 모바일 상단 바 진행선 | 사이트 전체에서의 진행 — (현재 순번 + 페이지 진행률) / 전체 |
| 미니맵 단계 펼침 | 다른 단계에 마우스·포커스를 두면 그 단계의 섹션 목록이 펼쳐진다 |
| Overview 흐름도 | 단계 카드가 왼쪽부터 차례로 나타나고 화살표가 그려진다 — 논증의 순서 |
| 페이지 전환 | View Transitions 지원 브라우저에서 미니맵은 제자리, 본문만 교체된다 |
| ← → 키 | 이전/다음 페이지. 단계 풀이에 포커스가 있으면 단계를 넘긴다 |

## 2. 단계 풀이 `.stepper` — 본문에 넣는 핵심 부품

식이 여러 단계로 만들어지거나, 데이터가 여러 처리를 거쳐 바뀌는 과정을 **한 단계씩**
보여 준다. 독자가 `다음` 을 눌러 넘긴다. 자동 재생하지 않는다.

```html
<figure class="stepper">
  <figcaption>Scaled dot-product attention 이 계산되는 순서</figcaption>
  <div class="step-view">
    <div data-step="1">$$S = QK^\top$$</div>
    <div data-step="2">$$S' = S / \sqrt{d_k}$$</div>
    <div data-step="3">$$A = \mathrm{softmax}(S')$$</div>
    <div data-step="4">$$\mathrm{Attention}(Q,K,V) = AV$$</div>
  </div>
  <ol class="step-notes">
    <li>query 와 key 를 내적해 위치 쌍마다 점수를 낸다.</li>
    <li>$d_k$ 가 크면 내적의 분산이 커지므로 $\sqrt{d_k}$ 로 나눈다 <span class="src">§3.2.1, p.4</span></li>
    <li>행마다 softmax 를 취해 가중치로 바꾼다.</li>
    <li>가중치로 value 를 섞는다.</li>
  </ol>
</figure>
```

- `data-step="n"` 요소는 n 단계부터 보이고, 지난 단계는 흐려지며, 현재 단계는 테두리로 강조된다.
- `data-step-only` 를 더하면 그 단계에서만 보인다 (같은 자리에 값이 바뀌는 표 등).
- `.step-notes` 의 n 번째 `<li>` 가 n 단계의 설명이다. 단계 수 = 설명 수로 맞춘다.
- SVG 도식에서도 쓴다 — `<g data-step="2">` 처럼 그룹 단위로.
- 언제 쓰나: 메커니즘 섹션의 핵심 식, 파이프라인 단계, 알고리즘 루프 한 바퀴, 장난감
  예시의 손계산. 섹션당 1~2개. 모든 식에 쓰면 읽는 속도만 느려진다.
- 단계는 3~7개. 단계 하나가 한 가지 변화만 담는다.

## 3. 기호 연동 `data-sym`

기호 표의 `<dt data-sym="dk">` 와 본문 문장의 `<span data-sym="dk">` 는 서로 마우스를
올리면 함께 밝아진다. 기호가 5개 이상인 식에서 쓴다.

```html
<dl class="symbols">
  <dt data-sym="dk">$d_k$</dt><dd>key 벡터의 차원 <span class="src">§3.2.1</span></dd>
</dl>
```

수식 안의 기호에는 붙일 수 없다 (MathML 출력은 속성을 넘기지 않는다).

## 4. 스크롤 등장 `.reveal`

화면에 들어올 때 살짝 떠오른다. **새 국면이 시작되는 블록에만** — Overview 의 큰 절,
결과 표, 핵심 정리. 문단마다 붙이지 않는다.

## 5. 쓰지 않는 것

- 자동 재생·반복 애니메이션 — 읽는 동안 시선을 뺏는다
- 스크롤에 묶인 시차(parallax) · 확대 — 위치 표시와 경쟁한다
- 0.6초가 넘는 전환
- 단계 풀이 안의 타이머
