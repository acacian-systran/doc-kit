# 치환 목록

`assets/lint.py`가 읽는 규칙표다. 모든 항목은 `검토`로 보고되며 자동으로 고치지 않는다.
두 열만 있는 표는 `all`·`literal`로 읽고, 필요할 때만 `검사 범위`와 `검출 방식` 열을 둔다.

**이 표는 예시다.** 표에 없다고 통과가 아니며, `SKILL.md`의 판정법(§2.5 주어 바꿔 넣기 ·
§2.7 목적어 바꿔 끼우기 · §5 부정된 쪽 지우기)을 함께 쓴다.

## 1. 어체

평서체 문서 안의 합니다체 종결을 찾는다. 송부 메일·요청문이 문서에 붙어 있으면 따로 떼어 낸다.

| 찾기 | 바꾸기 | 검사 범위 | 검출 방식 |
|---|---|---|---|
| `(?:습\|입\|됩\|합)니다(?=[.?!]\|\s*$)` | 평서체로 쓰거나 송부문으로 분리한다 | prose | regex |

## 6. AI 문투

이항 대조(`X가 아니라 Y다`)와 봉합 접속(`즉,` · `결국`)은 정상 표현일 때가 많아
`references/software-handoff.md`의 `의심` 갈래에 두었다. `--heuristic`에서만 보고한다.

### 6.1 도입 예고

| 쓰지 않는다 | 쓴다 |
|---|---|
| 결론부터 말하면 | (삭제하고 결론을 진술) |
| 핵심은 이렇다 | (삭제하고 핵심을 진술) |
| 여기서 중요한 것은 | (삭제하고 그 내용을 진술) |
| 한마디로 | (삭제) |

## 7. 바꾸지 않는 것

아래는 비유가 아니라 **용어**다. 풀어 옮기면 뜻이 달라진다. 가운데 열이 흔한 오역이다.

| 용어 | 흔한 오역 | 무엇이 틀리는가 |
|---|---|---|
| `드리프트` | 이탈 | 시간에 따른 **완만한** 이동이라는 뜻이 빠진다 |
| `뉴슨스` | 무해 결함 | 검출은 되었으나 수율에 영향이 없다는 **판정 결과**라는 뜻이 빠진다 |
| `오버레이` | 정렬 | 층간 정렬 **정확도**다. 장비 동작인 alignment와 다르다 |
| `CD` | 임계값 | 임계치수(critical dimension)다. threshold와 무관하다 |
| `dead code` | 죽은 코드 | 도달하지 않는 코드라는 정의가 흐려진다 |
| `liveness probe` | 생존 확인 | Kubernetes의 특정 검사 이름이다 |
| `idempotent` | 반복 가능 | 여러 번 실행해도 결과가 같다는 성질이 빠진다 |

조직·레포에 굳어진 표현도 임의로 바꾸지 않는다. 외부 문서에서는 처음 나올 때 한 번 풀어 쓴다.
