# 데이터 칸 · 레벨 페이지

그림의 타일 · 선은 이름만으로는 추상적이다. 실무진이 "실제로 어떤 데이터가 오가나"를 확인하게 하려고
타일과 선마다 **실행에서 나온 실제 값**을 붙이고, 큰 단계는 아래 그림으로 들어가게 한다.
처음 만든 계기는 rdb2ontology eGov RIGOR 그림(L0 실행 전체 → L1 table 하나 → L2 retrieval → L3)이다.
CTO 요구: "실무진은 추상적으로 알면 안 된다."

## 1. 무엇을 붙이나

| 자리 | 칸 이름(기본) | 담는 것 | 예 |
|---|---|---|---|
| 입력 · 저장소 타일 | 저장된 형태 | 그 자리의 파일 · 표 · 색인이 실제로 어떻게 생겼나 | schema JSON 앞부분, chunk 목록 전문, Turtle 앞 40행 |
| 단계 타일 | 저장된 형태(또는 `kind: "만든 것"`) | 그 단계가 남긴 기록 · 산출 | 호출 meta(시간 · 토큰), verdict JSON, 검증 결과 |
| 선 | 주고받는 데이터 | 그 선으로 넘어가는 값 그 자체 | 프롬프트 전문, 응답 글, 검색어, top-3 결과 |
| 판단 · 실패 선 | 주고받는 데이터 | 갈래로 넘어가는 것 + 이 실행에서 몇 번 지났나 | "hint 0개 · 이 run은 attempt 1에서 끝" |

한 칸에 `items` 여러 개(받는 것 / 만드는 것, 01 / 04 처럼). 각 item 에 `src` = 파일 경로와 행 범위 · 전체 행 수.

## 2. 값을 어떻게 얻나 — 손으로 옮기지 않는다

1. **실행 기록 파일에서 스크립트로 뽑는다.** 데이터 칸을 채우는 `*_data.py` 를 그림 spec 옆에 두고, 빌드할 때마다 파일을 다시 읽는다.
   행 범위는 고정 숫자 대신 머리글로 찾는다(`find_line(prompt, "[RETRIEVED DOCUMENTATION]")`) — 파일이 바뀌어도 어긋나지 않게.
2. **파일로 남지 않는 중간값**(chunk 글, 메모리의 index)은 코드의 함수 원문을 AST 로 떼어 같은 입력에 다시 돌린다.
   다시 만든 값이 실행 기록과 맞는지 **assert** 한다(개수, 그리고 기록된 결과가 그 안에 글자 그대로 있는지).
3. **끝내 볼 수 없는 값**(embedding vector 등)은 지어내지 않는다. "파일로 남지 않음 · 행 수 × 차원 · 정규화"처럼 사실만 적는다.
4. 길면 자르되 자른 것을 밝힌다(`… (703행 중 앞 200행)`). 프롬프트 · 응답처럼 그 선의 핵심인 글은 전문을 넣는다(칸 안에서 스크롤).
5. 이 실행에서 지나지 않은 길(retry 0회 등)도 칸을 둔다 — "0회"와 그 근거를 적는다. 그림에서 빼지 않는 것과 같은 원칙(grounding.md §3).

## 3. 레벨 페이지

- 한 장 = 한 레벨. L0 전체 실행 → L1 반복 한 번 → L2 단계 하나 → L3 그 단계의 세부. 레벨이 바뀌면 값 예시(어느 table · 어느 행)를 페이지 머리에 적는다.
- 들어가는 타일의 `data.href` = 아래 페이지 파일. 아래 페이지의 출구 타일(`Next table` 등) `data.href` = 위 페이지.
- `assets/site.py` 가 묶음을 빌드하고 레벨 목록(nav)을 넣고 href 를 검사한다. 위에서 들어오는 타일이 없는 페이지는 경고.
- 아래 페이지에서도 글자 원은 그 그림 안의 실행 순서로 새로 붙인다(위 그림 글자를 이어 쓰지 않음). 위 그림의 어느 타일을 펼친 것인지는 eyebrow · lede 에.

## 4. 조작 (build.py 가 넣는 것)

| 조작 | 결과 |
|---|---|
| 마우스 올리기 · Tab 으로 옮기기 | 오른쪽 칸 미리 보기 |
| 한 번 누르기 · Enter · Space | 칸 고정. 같은 타일을 다시 눌러도 유지 |
| 두 번 누르기 | `href` 가 있으면 아래 페이지로 |
| 칸 맨 위 링크 | 같은 곳으로(터치 화면에서 두 번 누르기 대신) |
| × · Esc · 빈 곳 누르기 | 닫기 |

같은 타일을 다시 눌러도 닫지 않는 이유: 두 번 누르기는 누르기 두 번을 먼저 일으키므로, 다시 누르기로 닫으면 들어가기 전에 칸이 깜빡인다.
들어갈 수 있는 타일은 점선 테두리로 구별된다.

## 5. 검사

- `check.py --render` 는 겹침만 본다. 데이터 칸은 `site.py` 의 경고(data 없는 타일 · 선)와 직접 눌러 보기로 확인한다.
- 눌러 보기: playwright 로 SVG 좌표를 화면 좌표로 바꿔(`getScreenCTM`) 선 위 한 점을 누른다. L 자 선은 묶음 상자 가운데가 빈 곳이라 locator.click 이 빗나간다.
- 외부에 내는 페이지면 칸 안 경로 · 값이 공개해도 되는지 먼저 본다(grounding.md §4). PNG 로 내보내면 칸은 사라진다.
